# Лаба 4. Вероятностные тесты простоты: Ферма, Соловея — Штрассена, Миллера — Рабина

Тест простоты — алгоритм, который для целого N > 1 определяет, простое оно или составное, не раскладывая N на множители.
Вероятностные тесты проверяют лишь часть условий критерия простоты. Для одного основания a ∈ {1, …, N−1} тест даёт ответ:

- **«N — составное»**: доказано, найден свидетель непростоты a;
- **«неизвестно»**: N простое, либо a — «лжец» для составного N.

Простое число всегда получает ответ «неизвестно». Тест повторяют для s случайных оснований: если ни разу не получено
«составное», N, вероятно, простое.

## Тесты

| Тест | Шаг 1 | Шаг 2: ответ «составное», если… | Вероятность ответа «составное» для составного N за раунд |
|---|---|---|---|
| Ферма | d = (a, N) > 1 | aᴺ⁻¹ ≢ 1 (mod N) | не гарантирована; для чисел Кармайкла P₀ = 1 − φ(N)/(N−1) |
| Соловей — Штрассен | d = (a, N) > 1 | a^((N−1)/2) ≢ (a/N) (mod N), (a/N) — символ Якоби | не менее 1/2 |
| Миллер — Рабин | d = (a, N) > 1 | N−1 = 2ᵗu; r_k = a^(2ᵏu) mod N, k = 0…t−1: нет ни r₀ = 1, ни r_k = −1 | не менее 3/4 |

После s раундов вероятность не обнаружить составность не превосходит (1 − P₀)ˢ, то есть 1/2ˢ и 1/4ˢ для двух последних тестов.
Тест Ферма хуже: существуют числа Кармайкла — составные N, для которых aᴺ⁻¹ ≡ 1 при всех a, взаимно простых с N.

Трудоёмкость одного раунда каждого теста — O(log³ N).

## Что реализовано

Модуль [`primality.py`](primality.py):

| Функция | Описание |
|---|---|
| `fermat_round(N, a)`, `solovay_strassen_round(N, a)`, `miller_rabin_round(N, a)` | один раунд с заданным основанием a ∈ {1, …, N−1}; `False` — «составное», `True` — «неизвестно» |
| `fermat_test(N, rounds=20, rng=None, info=None)`, `solovay_strassen_test(...)`, `miller_rabin_test(...)` | `rounds` раундов со случайными a из {1, …, N−1}; `False` — N составное (точно), `True` — все раунды дали «неизвестно» |
| `jacobi(a, n)` | символ Якоби (для теста Соловея — Штрассена) |
| `mr_decompose(N)`, `mr_sequence(N, a)` | разложение N − 1 = 2ᵗu и последовательность r₀, …, r_{t−1} |
| `liars(N, single)` | все основания, на которых раунд даёт «неизвестно» (для анализа вероятностей) |

Параметры: `rng` — генератор случайных чисел (с методом `randrange`, для воспроизводимости); `info` — словарь,
в который записываются число выполненных раундов, найденный свидетель `witness` и общий делитель `gcd` (если шаг 1 нашёл его).

Соглашения: N = 2 — простое; чётное N > 2 — составное; N ≤ 1 и `rounds < 1` — `ValueError`. Функции `*_round` требуют
нечётного N ≥ 3 и 1 ≤ a ≤ N − 1. Основание a = 1 допустимо (как на слайдах), но ничего не доказывает.

Замечание о шаге 1: для тестов Ферма и Миллера — Рабина шаг с НОД не меняет вердикт (если (a, N) > 1, то a не обратимо и
условие всё равно не выполняется), он лишь ускоряет работу и сразу даёт делитель. Для теста Соловея — Штрассена он необходим:
например, при N = 9, a = 3 имеем 3⁴ ≡ 0 = (3/9).

## Использование

```python
import random
from primality import fermat_test, solovay_strassen_test, miller_rabin_test, miller_rabin_round

miller_rabin_test(2**127 - 1)             # True: «неизвестно» (число простое)
miller_rabin_test(2**127 + 1)             # False: составное (делится на 3)

info = {}
miller_rabin_test(91 * 97, 20, random.Random(1), info)
print(info)                                # rounds, witness (свидетель), gcd

miller_rabin_round(2047, 2)                # True: 2047 = 23 * 89 - сильное псевдопростое по основанию 2
miller_rabin_round(2047, 3)                # False: основание 3 - свидетель
```

## Тесты

- символ Якоби сверяется с определением (произведение символов Лежандра по разложению n);
- простые числа принимаются всеми тестами на любом основании;
- все N < 3000 классифицируются так же, как точной проверкой простоты;
- структура множеств «лжецов» (перебор всех оснований для нечётных составных N < 700):
  у Ферма не более φ(N)/2, а для чисел Кармайкла ровно φ(N); у Соловея — Штрассена не более φ(N)/2;
  у Миллера — Рабина не более φ(N)/4 (исключение N = 9); сильные лжецы ⊂ эйлеровы лжецы ⊂ лжецы Ферма;
- числа Кармайкла до 3000 (561, 1105, 1729, 2465, 2821) и формула P₀ = 1 − φ(N)/(N−1) для N = 561;
- известные псевдопростые: 341 (Ферма, основание 2), 561 (Соловей — Штрассен), 2047 (Миллер — Рабин);
- большое число Кармайкла из конструкции (6k+1)(12k+1)(18k+1): Ферма ошибается, два других теста нет;
  доли обнаружения за раунд не ниже 1/2 и 3/4;
- граничные случаи, некорректные аргументы, шаг 1 (общий делитель), воспроизводимость, диапазон оснований.

## Сложность

Один раунд каждого теста — одно возведение в степень по модулю N, то есть O(log N) умножений по O(log² N): всего O(log³ N)
(в тесте Соловея — Штрассена добавляется символ Якоби за O(log² N)). Графики в `demo.ipynb` показывают, что время раунда
растёт не круче log³ N и для трёх тестов практически одинаково.
