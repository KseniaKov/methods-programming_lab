# Лаба 1. Алгоритмы Монтгомери в кольце вычетов ℤ_N

Пусть задано кольцо вычетов ℤ_N. Выберем R = bⁿ > N, где n — число цифр N в системе по основанию b и gcd(N, b) = 1.
Тогда существует разложение R·R′ − N·N′ = 1, где R′ = R⁻¹ mod N, N′ = −N⁻¹ mod R.

Вводится умножение по Монтгомери: x ∗ y = xyR⁻¹ mod N.
Отображение φ_R(x) = xR⁻¹ mod N — изоморфизм колец (ℤ_N; +, ×) → (ℤ_N; +, ∗).
Вычисление φ_R не требует деления на N: вместо него используются деление на R (сдвиг) и операции по модулю b.

## Что реализовано

Класс `Montgomery(N, b=2)` в [`montgomery.py`](montgomery.py):

| Метод | Описание |
|---|---|
| `redc(x)` | Алгоритм 1: φ_R(x) = xR⁻¹ mod N для 0 ≤ x < RN |
| `mont_product(x, y)` | Алгоритм 2: φ_R(xy) = xyR⁻¹ mod N, поразрядно по основанию b |
| `to_mont(x)` | φ_R⁻¹(x) = xR mod N = φ_R(x·R²), константа R² mod N считается один раз |
| `from_mont(x)` | φ_R(x) = xR⁻¹ mod N |
| `mul_mod(x, y)` | xy mod N |
| `mont_mul(x, y)` | умножение по Монтгомери x ∗ y = xyR mod N |
| `pow_naive(x, k)` | возведение в степень последовательными умножениями, O(k·n²) |
| `pow_mod(x, k)` | бинарное возведение в степень, O(log k · n²) |

Вспомогательные функции: `ext_gcd`, `inv_mod`, `montgomery_mul(x, y, N)`, `montgomery_pow(x, k, N)`.

## Использование

```python
from montgomery import Montgomery, montgomery_pow

M = Montgomery(1_000_000_007)        # b = 2 по умолчанию; N должно быть нечётным
M.mul_mod(123456, 654321)            # xy mod N
M.pow_mod(5, 10**18)                 # 5^(10^18) mod N

montgomery_pow(3, 10**5, 10**9 + 7, b=2**16)   # большее основание — меньше итераций
```

Ограничения: N > 1 и gcd(N, b) = 1 (при b = 2 модуль должен быть нечётным), показатель k ≥ 0.

## Тесты

Результаты всех алгоритмов сверяются с `x*y % N` и `pow(x, k, N)` на случайных данных
для оснований b ∈ {2, 3, 10, 16, 256, 2¹⁶}; проверяются также теорема об алгоритме 1
(результат равен xR⁻¹ mod N), разложение RR′ − NN′ = 1, граничные значения (0, 1, N−1),
нулевой показатель, малая теорема Ферма и модуль в 512 бит.

## Сложность

Одно произведение по Монтгомери — O(n²), как и у стандартного алгоритма, но без деления с остатком на N.
Возведение в степень: O(k·n²) в линейном варианте и O(log k · n²) в бинарном.
Графики в `demo.ipynb` это подтверждают.
