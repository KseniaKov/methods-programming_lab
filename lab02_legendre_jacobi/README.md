# Лаба 2. Символ Лежандра при помощи символа Якоби

Квадратное сравнение x² ≡ a (mod p) при нечётном простом p и (a, p) = 1 разрешимо тогда и только тогда,
когда символ Лежандра (a/p) = 1 (критерий Эйлера: a^((p−1)/2) ≡ (a/p) mod p).
Прямой алгоритм вычисления символа Лежандра требует факторизации числа, а символ Якоби — формальное обобщение
символа Лежандра на составные нечётные модули — позволяет её избежать. Трудоёмкость алгоритма O(log² n).

## Алгоритм

1. Заменить a на b: a ≡ b (mod n), |b| < n/2.
2. Представить b = (−1)^t · 2^k · c, c нечётно. Тогда (a/n) = (−1/n)^t · (2/n)^k · (c/n).
3. Вычислить (−1/n) = (−1)^((n−1)/2) и (2/n) = (−1)^((n²−1)/8), если t или k нечётны.
4. Для (c/n) применить закон взаимности (c/n) = (n/c) · (−1)^((c−1)/2 · (n−1)/2) и вернуться к шагу 1 с парой (n mod c, c).

Знаки из шагов 3 и 4 зависят только от остатков по модулю 4 и 8, поэтому степени −1 не вычисляются.
Алгоритм заканчивается, когда c = 1 (ответ ±1) или a делится на n (ответ 0).

## Что реализовано

Модуль [`legendre_jacobi.py`](legendre_jacobi.py):

| Функция | Описание |
|---|---|
| `jacobi(a, n, trace=None)` | символ Якоби (a/n), n нечётное натуральное; при `trace=[]` записывает шаги алгоритма |
| `legendre(a, p, check_prime=True)` | символ Лежандра (a/p) через символ Якоби; проверяет, что p нечётное простое |
| `num_solutions(a, p)` | число решений x² ≡ a (mod p): 1 + (a/p) |
| `is_probable_prime(n)` | тест Миллера — Рабина (детерминирован для n < 3,3·10²⁴) |
| `legendre_euler(a, p)` | проверочный: критерий Эйлера, `pow(a, (p-1)/2, p)` |
| `legendre_gauss(a, p)` | проверочный: критерий Гаусса, O(p) |
| `legendre_factorization(a, p)` | проверочный: первый алгоритм методички с факторизацией |
| `sign_minus_one`, `sign_two`, `sign_reciprocity` | знаки из шагов 3 и 4 |

Соглашения: если gcd(a, n) > 1, символ равен 0 (в методичке рассматривается только gcd = 1);
отрицательные a допустимы; n должно быть нечётным натуральным, иначе `ValueError`.

## Использование

```python
from legendre_jacobi import jacobi, legendre, num_solutions

legendre(1001, 9907)        # -1: сравнение x^2 = 1001 (mod 9907) не имеет решений
legendre(2, 7)              # 1:  3^2 = 2 (mod 7)
num_solutions(2, 7)         # 2 решения

steps = []
jacobi(1001, 9907, steps)   # шаги алгоритма попадут в список steps
print("\n".join(steps))

jacobi(2, 15)               # 1, но x^2 = 2 (mod 15) не имеет решений (замечание из методички)
```

## Тесты

Результат сверяется с независимыми способами:

- определение символа Лежандра: перебор квадратов по модулю p, все значения a для простых p < 300;
- критерий Эйлера (в том числе для простых чисел Мерсенна 2¹²⁷−1, 2⁵²¹−1, 2⁶⁰⁷−1);
- критерий Гаусса и первый алгоритм методички с факторизацией;
- определение символа Якоби через разложение n на простые множители;
- свойства символа Якоби из теоремы: периодичность, мультипликативность по обоим аргументам,
  (−1/n), (2/n), закон взаимности;
- следствие о числе вычетов и невычетов ((p−1)/2 каждых) и число решений x² ≡ a;
- замечание о том, что (a/n) = 1 не гарантирует разрешимость (пример (2/15));
- ошибочные входы, шаг 1 алгоритма (замена на вычет с |b| < n/2), числа длиной 40 000 бит.

## Сложность

Число итераций алгоритма O(log n), каждая стоит не больше O(log n): итого O(log² n), как в методичке.
Вариант с факторизацией использует пробные деления (O(√b), экспонента от длины p), на графиках
в `demo.ipynb` видно, как быстро он перестаёт быть пригодным.
