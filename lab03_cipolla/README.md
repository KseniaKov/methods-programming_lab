# Лаба 3. Вероятностный алгоритм Чипполы

Требуется найти решение уравнения x² ≡ a (mod p) для нечётного простого p, (a, p) = 1 и (a/p) = 1.
Достаточно найти один корень x₀: второй равен −x₀.

## Алгоритм

1. Случайно выбрать b, 0 ≤ b ≤ p − 1, такое что ((b² − 4a)/p) = −1.
2. Положить f(y) = y² − by + a ∈ ℤₚ[y].
3. x₀ — остаток от деления y^((p+1)/2) на f(y). Это константа, она и есть искомый корень.

**Почему это работает.** Дискриминант b² − 4a — квадратичный невычет, поэтому f неприводим над ℤₚ и
ℤₚ[y]/(f) — поле из p² элементов. Второй корень f равен b − y и совпадает с yᵖ (автоморфизм Фробениуса),
поэтому y^(p+1) = y · (b − y) = a, то есть x = y^((p+1)/2) удовлетворяет x² = a. У уравнения t² = a в этом поле
только два корня ±r, и они лежат в ℤₚ, поэтому x — константа.

**Реализация.** Элемент ℤₚ[y]/(f) хранится парой (u, v) = u + v·y. Умножение многочленов с последующим взятием
остатка по f (y² = by − a) даёт

    (u₁ + v₁y)(u₂ + v₂y) = (u₁u₂ − a·v₁v₂) + (u₁v₂ + u₂v₁ + b·v₁v₂)·y

Степень y^((p+1)/2) вычисляется бинарным возведением в степень в этом кольце.
Символ Лежандра для выбора b вычисляется по критерию Эйлера: a^((p−1)/2) mod p.

## Что реализовано

Модуль [`cipolla.py`](cipolla.py):

| Функция | Описание |
|---|---|
| `cipolla(a, p, rng=None, info=None)` | алгоритм Чипполы, возвращает x₀; `rng` — генератор случайных чисел (для воспроизводимости), `info` — словарь, в который записываются b, число попыток, дискриминант и коэффициенты f(y) |
| `sqrt_mod(a, p, rng=None)` | все решения x² ≡ a (mod p) по возрастанию |
| `fp2_mul(x, y, a, b, p)`, `fp2_pow(x, e, a, b, p)` | умножение и возведение в степень в ℤₚ[y]/(f) |
| `legendre_euler(a, p)` | символ Лежандра по критерию Эйлера |
| `is_probable_prime(n)` | тест Миллера — Рабина (детерминирован для n < 3,3·10²⁴) |
| `sqrt_3mod4(a, p)` | для сравнения: явная формула x₀ = a^((p+1)/4) при p ≡ 3 (mod 4) |

Соглашения: a приводится по модулю p (отрицательные и большие a допустимы); при a ≡ 0 корень равен 0;
если a — невычет или p не нечётное простое, выбрасывается `ValueError`.

## Использование

```python
import random
from cipolla import cipolla, sqrt_mod

cipolla(10, 13)                   # 6 или 7 (зависит от случайного b)
sqrt_mod(10, 13)                  # (6, 7): оба корня

info = {}
x0 = cipolla(10, 13, random.Random(1), info)   # воспроизводимый запуск
print(info)                       # b, число попыток, дискриминант, коэффициенты f(y)

p = 2**521 - 1
a = 123456789 ** 2 % p
x = cipolla(a, p)
assert x * x % p == a
```

## Тесты

- арифметика поля: умножение пар сверяется с независимой реализацией «умножить многочлены и взять остаток по f»,
  коммутативность, ассоциативность, степень против повторного умножения;
- теория: для вычета a подходит ровно (p − 1)/2 значений b, yᵖ = b − y, y^(p+1) = a, неприводимость f;
- корни для всех вычетов всех простых p < 300 совпадают с перебором, невычеты дают `ValueError`;
- простые с большой степенью двойки в p − 1 (2¹⁶+1, 119·2²³+1, 15·2²⁷+1, 2⁶⁴−2³²+1) и все классы p mod 8;
- большие простые: 2¹²⁷−1, 2²⁵⁵−19, 2⁵²¹−1, 2⁶⁰⁷−1;
- согласие с формулой для p ≡ 3 (mod 4), воспроизводимость при фиксированном `rng`,
  среднее число попыток ≈ 2p/(p−1);
- граничные случаи: a = 0, отрицательные a, неверный модуль.

## Сложность

Для вычета a подходят ровно (p − 1)/2 из p значений b, поэтому число попыток выбора b геометрически
распределено, и в среднем нужно 2p/(p − 1) ≈ 2 попытки. Каждая попытка — символ Лежандра за O(log³ p),
затем O(log p) умножений в поле, каждое из них стоит O(1) умножений по модулю p.
Итого средняя трудоёмкость O(log³ p), как в методичке. Графики в `demo.ipynb` показывают, что
время растёт не круче log³ p и отличается от явной формулы для p ≡ 3 (mod 4) лишь постоянным множителем.
