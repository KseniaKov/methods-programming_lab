## Запуск

```bash
pip install -r requirements.txt

# тесты одной лабы
cd lab01_montgomery && python -m unittest -v

# тесты всех лаб (нужен pytest)
pytest
```

## Как добавить новую лабу

1. Создать папку `labNN_<название>` и положить в неё код, тесты `test_<алгоритм>.py`, `demo.ipynb` и `README.md`.
2. Давать тестовым файлам разные имена в разных лабах (не `test_main.py` везде), иначе `pytest` выдаст конфликт имён.
3. Добавить строку в таблицу выше.
4. Закоммитить: `git add . && git commit -m "Add lab N: <название>"`.
